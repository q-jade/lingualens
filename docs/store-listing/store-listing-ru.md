Переводите веб с помощью выбранных вами провайдеров

LinguaLens — это расширение для перевода в браузере, созданное для гибкости. В отличие от инструментов, привязанных к одному облачному поставщику, LinguaLens позволяет вам решать, где выполняется каждый перевод: на вашем собственном компьютере с локальными LLM, через основные облачные API, через любой OpenAI-совместимый шлюз или через настраиваемый шаблон HTTP API. Установите провайдера по умолчанию, добавьте цепочку резервных провайдеров — и перевод продолжится, даже если основной сервис недоступен.

ПОЧЕМУ LINGUALENS

• Свой бэкенд — Никакой привязки к одному сервису перевода.
• Локальные решения прежде всего — Используйте Ollama или LM Studio, чтобы конфиденциальный текст оставался на вашем устройстве.
• Облако, когда нужно — OpenAI, DeepSeek, DeepL, Google Cloud Translation и другие.
• OpenAI-совместимые эндпоинты — Работает с любым шлюзом или прокси, предоставляющим /v1/chat/completions.
• Настраиваемый HTTP API — Настройте метод, заголовки, шаблон тела JSON и путь ответа для собственных систем.
• Устойчивый рабочий процесс — Упорядоченные резервные провайдеры на случай сбоя основного во время сеанса.
• Честная модель конфиденциальности — LinguaLens не использует собственные серверы перевода; вы сами решаете, кто получает ваш текст.
• Многоязычный интерфейс — 9 языков интерфейса: English, 中文 (упр./трад.), 日本語, 한국어, Français, Deutsch, Español, Русский.

ПРОВАЙДЕРЫ ПЕРЕВОДА

Локальные
• Ollama (предустановка по умолчанию) — http://localhost:11434
• LM Studio — Использует собственный локальный API LM Studio

Облачные предустановки
• OpenAI — api.openai.com
• DeepSeek — api.deepseek.com
• DeepL — Бесплатный или Pro API эндпоинт
• Google Cloud Translation — translation.googleapis.com

Продвинутые
• OpenAI-совместимый — Любой пользовательский base URL с /v1/chat/completions
• Пользовательский API — Полностью настраиваемый шаблон HTTP-запроса

Проверьте подключение каждого провайдера в Настройках перед сохранением. API-ключи (если требуются) хранятся локально в хранилище браузера.

ВОЗМОЖНОСТИ

Перевод выделенного текста
Выделите текст на любой обычной веб-странице. Выберите один из четырёх режимов активации: плавающий значок рядом с выделением (по умолчанию), мгновенный перевод при выделении, удержание клавиши-модификатора для активации или отключение активации. Откройте панель, чтобы просмотреть результат, повторить при ошибке, скопировать перевод или закрыть её. Закрепите панель, чтобы она оставалась открытой при нескольких выделениях. Также доступно через контекстное меню или нажмите Alt+T для перевода текущего выделения в один шаг. Переключайте активного провайдера перевода в любое время из заголовка панели.

Двуязычный перевод всей страницы
Преобразуйте статьи, документы и длинные страницы в режим двуязычного чтения или полной замены, не покидая сайт. Переключайтесь между режимами в любое время из строки состояния. Запустите из всплывающего окна («Перевести эту страницу»), контекстного меню страницы или Alt+Shift+T. Строка состояния показывает прогресс и позволяет остановить перевод, восстановить исходный текст или сменить режим отображения.

Режимы перевода страницы
• Качество — Более крупные фрагменты, лучший контекст для перевода с LLM
• Скорость — Более мелкие фрагменты, более быстрые постепенные обновления

Переводчик во всплывающем окне
Нажмите на значок на панели инструментов, чтобы вставить или ввести текст, выбрать целевой язык и мгновенно перевести. Перейдите в Настройки или запустите перевод всей страницы на активной вкладке.

Боковая панель (Chrome 114+)
Откройте специальное рабочее пространство перевода из всплывающего окна. Установите исходный и целевой языки, поменяйте их местами, просматривайте результаты и изучайте историю недавних переводов, хранящуюся локально на вашем устройстве.

Настройки и знакомство
При первой установке Настройки открываются автоматически с кратким руководством по настройке. Настройте языки, провайдера по умолчанию, порядок резервных провайдеров, шаблон промпта LLM и параметры для каждого провайдера, такие как отключение вывода «thinking» на поддерживаемых моделях для более быстрых и чистых переводов.

Производительность
Встроенный кэш переводов сокращает повторные вызовы API для одинакового текста во время просмотра.

СОЧЕТАНИЯ КЛАВИШ

Alt+T — Перевести выделение
Alt+Shift+T — Перевести всю страницу
Alt+M — Переключить режим активации выделения (значок → мгновенный → клавиша-модификатор → выкл.)

Если сочетания конфликтуют с другими расширениями, переназначьте сочетания LinguaLens в chrome://extensions/shortcuts.

НАЧАЛО РАБОТЫ

1. Установите LinguaLens. Настройки открываются при первом запуске.
2. Прокрутите до раздела «Провайдеры перевода». Включите хотя бы один бэкенд.
3. При необходимости укажите base URL, модель и API-ключ. Нажмите «Проверить», затем «Сохранить настройки».
4. Откройте любую обычную https-страницу и попробуйте перевод выделения или всей страницы.

Совет по Ollama: выполните `ollama pull llama3` и запустите Ollama с OLLAMA_ORIGINS="chrome-extension://*", если браузер не может подключиться.

КОНФИДЕНЦИАЛЬНОСТЬ

LinguaLens не использует собственные серверы перевода. Переводимый вами текст отправляется только тем провайдерам, которых вы включили. Настройки и API-ключи остаются на вашем устройстве. См. URL политики конфиденциальности на этой странице. Ознакомьтесь с политиками сторонних сервисов для любых используемых вами облачных API.

ОГРАНИЧЕНИЯ

• Не работает на ограниченных страницах (chrome://, Chrome Web Store и т.д.)
• Требуется хотя бы один настроенный и работающий провайдер для перевода
• Для боковой панели требуется Chromium 114+
• Очень длинные страницы могут потребовать времени и нескольких вызовов API
