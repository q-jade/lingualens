お好みのプロバイダでウェブを翻訳

LinguaLens は柔軟性を重視したブラウザ翻訳拡張機能です。単一のクラウドベンダーに縛られるツールとは異なり、LinguaLens では翻訳の実行場所を自由に選べます：ローカル LLM で自分のマシン上、主要なクラウド API 経由、OpenAI 互換ゲートウェイ、またはカスタマイズ可能な HTTP API テンプレート。デフォルトプロバイダを設定し、オプションのフォールバックチェーンを追加すれば、メインのサービスが利用できない時も翻訳を継続できます。

LINGUALENS を選ぶ理由

• 自分のバックエンドを持ち込める — 単一の翻訳サービスにロックインされません。
• ローカルファースト — Ollama や LM Studio を使用すれば、機密テキストをデバイス内に留められます。
• 必要な時にクラウド — OpenAI、DeepSeek、DeepL、Google Cloud Translation などに対応。
• OpenAI 互換エンドポイント — /v1/chat/completions を公開するあらゆるゲートウェイやプロキシと連携。
• カスタム HTTP API — メソッド、ヘッダー、JSON ボディテンプレート、レスポンスパスを設定して独自スタックに対応。
• 堅牢なワークフロー — デフォルトがセッション中に失敗しても、順次フォールバックプロバイダがカバー。
• 誠実なプライバシーモデル — LinguaLens は翻訳サーバーを運営しません。テキストの送信先はあなたが決定します。
• 多言語インターフェース — 9言語対応：English、中文（簡/繁）、日本語、한국어、Français、Deutsch、Español、Русский。

翻訳プロバイダ

ローカル
• Ollama（デフォルトプリセット）— http://localhost:11434
• LM Studio — LM Studio のネイティブローカル API を使用

クラウドプリセット
• OpenAI — api.openai.com
• DeepSeek — api.deepseek.com
• DeepL — 無料版またはプロ版 API エンドポイント
• Google Cloud Translation — translation.googleapis.com

高度な設定
• OpenAI 互換 — /v1/chat/completions を公開するユーザー指定のベース URL
• カスタム API — 完全に設定可能な HTTP リクエストテンプレート

各プロバイダは保存前に設定画面から接続を検証できます。API キー（必要な場合）はブラウザのローカルストレージに保存されます。

機能

選択テキスト翻訳
任意のウェブページでテキストを選択（ブラウザで開いた PDF ドキュメントを含む）。4つのトリガーモードから選択できます：選択付近のフローティングアイコン（デフォルト）、選択即時翻訳、修飾キー長押しでトリガー、またはオフ。パネルを開いて結果を表示し、失敗時に再試行、翻訳をコピー、または閉じることができます。パネルを固定して複数回の選択にわたって開いたままにすることも可能。右クリックメニューからも利用でき、Alt+T で現在の選択をワンステップで翻訳します。パネルヘッダーからいつでも使用中の翻訳プロバイダや目標言語を切り替え、即座に再翻訳できます。コンテンツスクリプトが実行できないページ（ブラウザ内部ページ、拡張機能ストア等）では、右クリックの「翻訳」が選択テキストを自動的に開くサイドパネルにルーティングします。

全ページバイリンガル翻訳
記事、ドキュメント、長文ページを、サイトを離れることなくインラインバイリンガル表示または置換表示に変換。ステータスバーからいつでも表示モードを切り替え可能。ポップアップ（「このページを翻訳」）、ページ右クリックメニュー、または Alt+Shift+T から開始。ステータスバーに進捗が表示され、翻訳の停止、原文の復元、表示モードの切り替えができます。

ページ翻訳モード
• 品質重視 — 大きなチャンクで LLM 翻訳の文脈を向上
• 速度重視 — 小さなチャンクで高速なプログレッシブ更新

ポップアップ翻訳
ツールバーアイコンをクリックしてテキストを貼り付けまたは入力し、ターゲット言語を選んで即座に翻訳。設定にジャンプしたり、アクティブなタブで全ページ翻訳を開始できます。

サイドパネル（Chrome 114+）
ポップアップから専用の翻訳ワークスペースを開きます。ソース言語とターゲット言語の設定、言語の入れ替え、結果の表示、デバイスにローカル保存された最近の翻訳履歴の閲覧が可能です。

設定とオンボーディング
初回インストール時に設定画面が自動的に開き、簡単なセットアップガイドが表示されます。言語、デフォルトプロバイダ、フォールバック順序、LLM プロンプトテンプレート（基本と追加）、およびプロバイダごとのオプション（対応モデルで「thinking」出力を無効にしてより高速でクリーンな翻訳を得るなど）を設定できます。

パフォーマンス
内蔵の翻訳キャッシュにより、閲覧中の同一テキストに対する重複 API 呼び出しを削減します。

キーボードショートカット

Alt+T — 選択テキストを翻訳
Alt+Shift+T — ページ全体を翻訳
Alt+M — 選択トリガーモードを切り替え（アイコン → 即時 → 修飾キー → オフ）

ショートカットが他の拡張機能と競合する場合は、chrome://extensions/shortcuts で LinguaLens のショートカットを再割り当てしてください。

はじめ方

1. LinguaLens をインストール。初回起動時に設定が開きます。
2. 翻訳プロバイダまでスクロールし、少なくとも1つのバックエンドを有効にします。
3. 必要に応じてベース URL、モデル、API キーを設定。「検証」をクリックし、「設定を保存」します。
4. 任意の通常の https ページを開き、選択翻訳または全ページ翻訳をお試しください。

Ollama のヒント：`ollama pull llama3` を実行し、ブラウザが接続できない場合は OLLAMA_ORIGINS="chrome-extension://*" で Ollama を起動してください。

プライバシー

LinguaLens は独自の翻訳サーバーを運営しません。翻訳されるテキストは、あなたが有効にしたプロバイダにのみ送信されます。設定と API キーはお使いのデバイスに保存されます。このリストのプライバシーポリシー URL をご覧ください。使用するクラウド API のサードパーティポリシーもご確認ください。

制限事項

• 全ページ翻訳は制限付きページ（chrome://、ブラウザ内部ページ等）では動作しません。そのようなページでの選択テキスト翻訳はサイドパネルにルーティングされます（Chromium 114 以上）
• 少なくとも1つの設定済みで動作可能なプロバイダが必要です
• サイドパネルは Chromium 114 以上が必要です
• 非常に長いページでは時間と複数回の API 呼び出しが必要になる場合があります
