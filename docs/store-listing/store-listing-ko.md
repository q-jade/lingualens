선택한 제공업체로 웹을 번역하세요

LinguaLens는 유연성을 위해 설계된 브라우저 번역 확장 프로그램입니다. 단일 클라우드 벤더에 종속된 도구와 달리, LinguaLens를 사용하면 번역 실행 위치를 직접 결정할 수 있습니다: 로컬 LLM으로 내 컴퓨터에서, 주요 클라우드 API를 통해, OpenAI 호환 게이트웨이를 거쳐, 또는 사용자 정의 가능한 HTTP API 템플릿으로. 기본 제공업체를 설정하고 선택적 폴백 체인을 추가하면 주 서비스를 사용할 수 없을 때도 번역이 계속됩니다.

LINGUALENS를 선택하는 이유

• 나만의 백엔드 사용 — 하나의 번역 서비스에 종속되지 않습니다.
• 로컬 우선 — Ollama 또는 LM Studio를 사용하여 민감한 텍스트를 기기에 보관하세요.
• 필요할 때 클라우드 — OpenAI, DeepSeek, DeepL, Google Cloud Translation 등 지원.
• OpenAI 호환 엔드포인트 — /v1/chat/completions를 노출하는 모든 게이트웨이 또는 프록시와 연동.
• 사용자 정의 HTTP API — 메서드, 헤더, JSON 본문 템플릿, 응답 경로를 구성하여 독자적인 스택에 대응.
• 탄력적인 워크플로 — 기본값이 세션 중 실패해도 순차적 폴백 제공업체가 커버.
• 정직한 개인정보 보호 모델 — LinguaLens는 번역 서버를 운영하지 않습니다. 텍스트 전송 대상을 사용자가 결정합니다.
• 다국어 인터페이스 — 9개 UI 언어: English, 中文(간체/번체), 日本語, 한국어, Français, Deutsch, Español, Русский.

번역 제공업체

로컬
• Ollama (기본 프리셋) — http://localhost:11434
• LM Studio — LM Studio의 네이티브 로컬 API 사용

클라우드 프리셋
• OpenAI — api.openai.com
• DeepSeek — api.deepseek.com
• DeepL — 무료 또는 Pro API 엔드포인트
• Google Cloud Translation — translation.googleapis.com

고급
• OpenAI 호환 — /v1/chat/completions를 노출하는 사용자 지정 base URL
• 사용자 정의 API — 완전히 구성 가능한 HTTP 요청 템플릿

각 제공업체는 저장 전에 설정에서 연결을 확인할 수 있습니다. API 키(필요한 경우)는 브라우저 로컬 저장소에 저장됩니다.

기능

선택 영역 번역
일반 웹 페이지에서 텍스트를 선택하세요. 네 가지 트리거 모드 중에서 선택할 수 있습니다: 선택 영역 근처의 플로팅 아이콘(기본값), 선택 즉시 번역, 보조 키 길게 누르기로 트리거, 또는 끄기. 패널을 열어 결과를 확인하고, 실패 시 재시도하고, 번역을 복사하거나 닫을 수 있습니다. 패널을 고정하여 여러 번의 선택에 걸쳐 열린 상태를 유지할 수도 있습니다. 우클릭 컨텍스트 메뉴로도 이용 가능하며, Alt+T로 현재 선택을 한 번에 번역합니다. 패널 헤더에서 언제든지 활성 번역 제공업체를 전환할 수 있습니다.

전체 페이지 이중언어 번역
기사, 문서, 긴 페이지를 사이트를 떠나지 않고 인라인 이중언어 또는 교체 읽기 모드로 변환합니다. 상태 표시줄에서 언제든지 표시 모드를 전환할 수 있습니다. 팝업("이 페이지 번역"), 페이지 우클릭 메뉴, 또는 Alt+Shift+T로 시작합니다. 상태 표시줄에 진행 상황이 표시되며 번역 중지, 원본 복원, 표시 모드 전환이 가능합니다.

페이지 번역 모드
• 품질 우선 — 더 큰 청크로 LLM 번역에 더 나은 맥락 제공
• 속도 우선 — 더 작은 청크로 더 빠른 점진적 업데이트

팝업 번역기
도구 모음 아이콘을 클릭하여 텍스트를 붙여넣거나 입력하고, 대상 언어를 선택하여 즉시 번역합니다. 설정으로 이동하거나 활성 탭에서 전체 페이지 번역을 시작할 수 있습니다.

사이드 패널 (Chrome 114+)
팝업에서 전용 번역 작업 공간을 엽니다. 소스 및 대상 언어 설정, 언어 교환, 결과 확인, 기기에 로컬로 저장된 최근 번역 기록을 탐색할 수 있습니다.

설정 및 온보딩
최초 설치 시 설정이 자동으로 열리고 간단한 설정 가이드가 표시됩니다. 언어, 기본 제공업체, 폴백 순서, LLM 프롬프트 템플릿, 그리고 제공업체별 옵션(지원 모델에서 "thinking" 출력을 비활성화하여 더 빠르고 깔끔한 번역을 얻는 등)을 구성할 수 있습니다.

성능
내장 번역 캐시가 브라우징 중 동일한 텍스트에 대한 중복 API 호출을 줄입니다.

키보드 단축키

Alt+T — 선택 영역 번역
Alt+Shift+T — 전체 페이지 번역
Alt+M — 선택 트리거 모드 전환 (아이콘 → 즉시 → 보조 키 → 끄기)

단축키가 다른 확장 프로그램과 충돌하는 경우 chrome://extensions/shortcuts에서 LinguaLens 단축키를 재할당하세요.

시작하기

1. LinguaLens 설치. 최초 실행 시 설정이 열립니다.
2. 번역 제공업체까지 스크롤하여 최소 하나의 백엔드를 활성화합니다.
3. 필요에 따라 base URL, 모델, API 키를 설정합니다. "확인"을 클릭한 후 "설정 저장"을 클릭합니다.
4. 일반 https 페이지를 열고 선택 번역 또는 전체 페이지 번역을 시도해 보세요.

Ollama 팁: `ollama pull llama3`을 실행하고 브라우저가 연결할 수 없는 경우 OLLAMA_ORIGINS="chrome-extension://*"로 Ollama를 시작하세요.

개인정보 보호

LinguaLens는 자체 번역 서버를 운영하지 않습니다. 번역되는 텍스트는 사용자가 활성화한 제공업체로만 전송됩니다. 설정 및 API 키는 기기에 보관됩니다. 이 목록의 개인정보처리방침 URL을 참조하세요. 사용하는 클라우드 API의 제3자 정책도 검토하시기 바랍니다.

제한 사항

• 제한된 페이지(chrome://, Chrome 웹 스토어 등)에서는 작동하지 않습니다
• 최소 하나의 구성되고 작동하는 제공업체가 필요합니다
• 사이드 패널은 Chromium 114 이상이 필요합니다
• 매우 긴 페이지는 시간이 걸리고 여러 번의 API 호출이 필요할 수 있습니다
