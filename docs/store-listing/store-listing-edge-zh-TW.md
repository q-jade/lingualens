用你選擇的翻譯服務翻譯網頁

LinguaLens 是一款注重靈活性的瀏覽器翻譯擴充功能。與綁定單一雲端服務商的工具不同，LinguaLens 讓你決定每次翻譯在哪裡執行：在本機用私有 LLM、透過主流雲端 API、經由任何 OpenAI 相容閘道，或透過可自訂的 HTTP API 範本。設定預設翻譯服務、新增可選的備用鏈，即使主要服務無法使用，翻譯仍可繼續進行。

為什麼選擇 LINGUALENS

• 自帶後端 — 不鎖定任何翻譯服務商。
• 本機優先 — 使用 Ollama 或 LM Studio，敏感文字無需離開你的裝置。
• 需要時上雲 — 支援 OpenAI、DeepSeek、DeepL、Google Cloud Translation 等。
• OpenAI 相容端點 — 可對接任何暴露 /v1/chat/completions 的閘道和代理。
• 自訂 HTTP API — 可設定請求方法、請求標頭、JSON 請求主體範本和回應路徑，配接私有系統。
• 彈性工作流程 — 按順序設定備用翻譯服務，預設服務故障時自動切換。
• 透明隱私模型 — LinguaLens 不執行任何翻譯伺服器；你決定文字傳送到哪裡。
• 多語言介面 — 支援 9 種 UI 語言：English、中文（簡/繁）、日本語、한국어、Français、Deutsch、Español、Русский。

翻譯服務

本機
• Ollama（預設預設值）— 執行於 localhost:11434
• LM Studio — 使用 LM Studio 的原生本機 API

雲端預設
• OpenAI、DeepSeek、DeepL（免費版 & 專業版）、Google Cloud Translation

進階
• OpenAI 相容 — 任意使用者指定的 base URL，對接 /v1/chat/completions
• 自訂 API — 完全可設定的 HTTP 請求範本

每個服務可在設定中驗證連通性後再儲存。API 金鑰（如需要）僅儲存在瀏覽器本機儲存空間中。

功能特性

劃詞翻譯
在任意網頁上選取文字（包括瀏覽器中開啟的 PDF 文件），可從四種觸發模式中選擇：選取區附近顯示浮動圖示（預設）、選取即譯、按住輔助鍵觸發或關閉觸發。開啟面板可檢視翻譯結果、失敗時重試、複製譯文或關閉。可固定面板，使其在多次選取中保持開啟。也可透過右鍵選單觸發，或按 Alt+T 一鍵翻譯目前選取內容。可隨時從面板頂部切換目前使用的翻譯服務。在內容腳本無法執行的頁面上（瀏覽器內部頁面、擴充功能商店等），右鍵「翻譯」會將選取內容路由到自動開啟的側邊面板。

全頁雙語翻譯
將文章、文件和長頁面轉換為內嵌式雙語或替換式閱讀模式，無需離開目前網站。可隨時從狀態列切換顯示模式。可透過彈出視窗中的「翻譯此頁面」、頁面右鍵選單或 Alt+Shift+T 啟動。狀態列顯示翻譯進度，支援隨時停止翻譯、還原原文或切換顯示模式。

頁面翻譯模式
• 品質優先 — 較大文字區塊，為 LLM 翻譯提供更好的上下文
• 速度優先 — 較小文字區塊，更快的漸進式更新

彈出視窗翻譯器
按一下工具列圖示即可貼上或輸入文字，選取目標語言，即時翻譯。可快速跳轉到設定頁，或對目前分頁啟動全頁翻譯。

側邊面板
從彈出視窗開啟獨立的翻譯工作區。設定來源語言和目標語言、交換語言、檢視翻譯結果，以及瀏覽儲存在本機裝置上的歷史翻譯記錄。需要 Chromium 114 或更高版本。

設定與引導
首次安裝時，設定頁面會自動開啟並顯示簡短的設定指南。可設定語言、預設翻譯服務、備用順序、LLM 提示詞範本，以及各服務的獨立選項（如在支援的模型上停用「思考」輸出以獲得更快更簡潔的翻譯）。

效能
內建翻譯快取可減少瀏覽過程中對相同文字的重複 API 呼叫。

鍵盤快速鍵

Alt+T — 翻譯選取內容
Alt+Shift+T — 翻譯整個頁面
Alt+M — 切換劃詞觸發模式（圖示 → 即時 → 輔助鍵 → 關閉）

如快速鍵與其他擴充功能衝突，請在瀏覽器的擴充功能快速鍵設定中重新指派。

快速上手

1. 安裝 LinguaLens。首次執行時設定頁面自動開啟。
2. 捲動到「翻譯服務」部分。啟用至少一個翻譯後端。
3. 根據需要設定 base URL、模型和 API 金鑰。按一下「驗證」，然後「儲存設定」。
4. 開啟任意普通 https 頁面，嘗試劃詞翻譯或全頁翻譯。

Ollama 提示：執行 ollama pull llama3 並設定 OLLAMA_ORIGINS 環境變數為你的擴充功能來源（如果瀏覽器無法本機連線）。

隱私

LinguaLens 不執行自有翻譯伺服器。你翻譯的文字僅傳送到你啟用的服務。設定和 API 金鑰儲存在你的裝置上。詳見本商品頁面上的隱私權政策連結。使用任何雲端 API 前，請查閱相應第三方的隱私權政策。

限制

• 全頁翻譯無法在受限頁面上執行（瀏覽器內部頁面、擴充功能商店頁面等）；此類頁面上的劃詞翻譯會路由到側邊面板（Chromium 114+）
• 需要至少設定一個可用的翻譯服務才能運作
• 側邊面板需要 Chromium 114+
• 非常長的頁面可能需要較長時間和多次 API 呼叫
