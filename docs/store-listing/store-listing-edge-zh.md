用你选择的翻译服务翻译网页

LinguaLens 是一款注重灵活性的浏览器翻译扩展。与绑定单一云服务商的工具不同，LinguaLens 让你决定每次翻译在哪里运行：在本地用私有 LLM、通过主流云端 API、经由任何 OpenAI 兼容网关，或通过可自定义的 HTTP API 模板。设置默认翻译服务、添加可选的备用链，即使主服务不可用，翻译仍可继续进行。

为什么选择 LINGUALENS

• 自带后端 — 不锁定任何翻译服务商。
• 本地优先 — 使用 Ollama 或 LM Studio，敏感文本无需离开你的设备。
• 需要时上云 — 支持 OpenAI、DeepSeek、DeepL、Google Cloud Translation 等。
• OpenAI 兼容端点 — 可对接任何暴露 /v1/chat/completions 的网关和代理。
• 自定义 HTTP API — 可配置请求方法、请求头、JSON 请求体模板和响应路径，适配私有系统。
• 弹性工作流 — 按顺序配置备用翻译服务，默认服务故障时自动切换。
• 透明隐私模型 — LinguaLens 不运行任何翻译服务器；你决定文本发送到哪里。
• 多语言界面 — 支持 9 种 UI 语言：English、中文（简/繁）、日本語、한국어、Français、Deutsch、Español、Русский。

翻译服务

本地
• Ollama（默认预设）— 运行于 localhost:11434
• LM Studio — 使用 LM Studio 的原生本地 API

云端预设
• OpenAI、DeepSeek、DeepL（免费版 & 专业版）、Google Cloud Translation

高级
• OpenAI 兼容 — 任意用户指定的 base URL，对接 /v1/chat/completions
• 自定义 API — 完全可配置的 HTTP 请求模板

每个服务可在设置中验证连通性后再保存。API 密钥（如需要）仅存储在浏览器本地存储中。

功能特性

划词翻译
在普通网页上选中文本，可从四种触发模式中选择：选区附近显示浮动图标（默认）、选中即译、按住修饰键触发或关闭触发。打开面板可查看翻译结果、失败时重试、复制译文或关闭。可固定面板，使其在多次选词中保持打开。也可通过右键菜单触发，或按 Alt+T 一键翻译当前选中内容。可随时从面板顶部切换当前使用的翻译服务。

全页双语翻译
将文章、文档和长页面转换为内嵌式双语或替换式阅读模式，无需离开当前网站。可随时从状态栏切换显示模式。可通过弹窗中的"翻译此页面"、页面右键菜单或 Alt+Shift+T 启动。状态栏显示翻译进度，支持随时停止翻译、恢复原文或切换显示模式。

页面翻译模式
• 质量优先 — 较大文本块，为 LLM 翻译提供更好的上下文
• 速度优先 — 较小文本块，更快的渐进式更新

弹窗翻译器
点击工具栏图标即可粘贴或输入文本，选择目标语言，即时翻译。可快速跳转到设置页，或对当前标签页启动全页翻译。

侧边面板
从弹窗打开独立的翻译工作区。设置源语言和目标语言、交换语言、查看翻译结果，以及浏览存储在本地设备上的历史翻译记录。需要 Chromium 114 或更高版本。

设置与引导
首次安装时，设置页面会自动打开并显示简短的设置指南。可配置语言、默认翻译服务、备用顺序、LLM 提示词模板，以及各服务的独立选项（如在支持的模型上禁用"思考"输出以获得更快更简洁的翻译）。

性能
内置翻译缓存可减少浏览过程中对相同文本的重复 API 调用。

键盘快捷键

Alt+T — 翻译选中内容
Alt+Shift+T — 翻译整个页面
Alt+M — 切换划词触发模式（图标 → 即时 → 按键 → 关闭）

如快捷键与其他扩展冲突，请在浏览器的扩展快捷键设置中重新分配。

快速上手

1. 安装 LinguaLens。首次运行时设置页面自动打开。
2. 滚动到"翻译服务"部分。启用至少一个翻译后端。
3. 根据需要设置 base URL、模型和 API 密钥。点击"验证"，然后"保存设置"。
4. 打开任意普通 https 页面，尝试划词翻译或全页翻译。

Ollama 提示：运行 ollama pull llama3 并设置 OLLAMA_ORIGINS 环境变量为你的扩展来源（如果浏览器无法本地连接）。

隐私

LinguaLens 不运行自有翻译服务器。你翻译的文本仅发送到你启用的服务。设置和 API 密钥保存在你的设备上。详见本商品页面上的隐私政策链接。使用任何云端 API 前，请查阅相应第三方的隐私政策。

限制

• 无法在受限页面上运行（浏览器内部页面、扩展商店页面等）
• 需要至少配置一个可用的翻译服务才能工作
• 侧边面板需要 Chromium 114+
• 非常长的页面可能需要较长时间和多次 API 调用
